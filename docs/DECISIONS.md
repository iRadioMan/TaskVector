# Принятые решения и ограничения

- В проекте используется нативная схема SQLite, создаваемая при старте; отдельные наборы goose-миграций SQLite и PostgreSQL ещё не подключены.
- Первый исполняемый вертикальный срез ориентирован на локальную разработку с SQLite. PostgreSQL, CLI миграции/резервного копирования, восстановление и Docker ещё не реализованы.
- Поля регистрации по умолчанию выбирают `ru`, системную тему и часовой пояс браузера; язык и тему можно менять в браузере и они сохраняются в `localStorage`.
- Пароли сохраняются Argon2id PHC-хешами с параметрами m=64 МиБ, t=3, p=2. Ограничение попыток входа ещё не реализовано.
- Категории создаются через кнопку «+»; переименование и подтверждение удаления категории будут добавлены в следующем срезе.
- В прототипе не реализованы уведомления, фокус-ловушка модальных окон, полный профиль, фильтр календаря, пагинация и E2E.
